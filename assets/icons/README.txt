Place your launcher icon PNG here as:

  assets/icons/medimitra_logo.png

Recommended:
- 1024x1024 PNG
- Transparent background (or solid white)
- Keep logo centered with padding so it doesn’t get cropped in adaptive icons

After adding the file, run:
  flutter pub get
  dart run flutter_launcher_icons

Then rebuild your APK:
  flutter build apk --release
